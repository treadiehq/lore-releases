# Lore Releases

[Lore](https://uselore.co) gives coding agents a shared engineering memory:
teach one agent once, and the others learn too.

This repository contains its CLI binary releases.

## Install

```sh
curl -fsSL https://uselore.co/install.sh | sh
```

Each release ships `lore-linux-x64`, `lore-linux-arm64`, `lore-darwin-x64`,
`lore-darwin-arm64`, the `install.sh` installer, and a `SHA256SUMS` manifest.
The installer verifies checksums before installing.
